More ways to add books

Sources, Hardcover token and Google Books key

Paste your Hardcover token once. It is kept only in this browser on this device, never in the library database or the code. Create or renew a token. Tokens expire, so renew it if Hardcover stops working.

Google Books key (optional). Without a key, Google Books shares a small free limit and often says HTTP 429. Your own free key fixes that. It is kept only in this browser on this device, never in the library database or the code. Enable the Books API and create a key.

Bulk add, Goodreads file and barcode scan

Paste ISBNs (one per line), scan barcodes with your phone camera, or import your own Goodreads export file. Press Look up, review the list, then add the books you want. Up to 150 new books are looked up at a time.
